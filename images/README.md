# مجلد الصور (images)

ضع صورك الحقيقية هنا بنفس الأسماء التالية حتى تظهر تلقائيًا في الموقع (بدون الحاجة لتعديل الكود):

| اسم الملف المطلوب | أين يظهر |
|---|---|
| `logo.png` | شعار المصنع (الهيدر، صفحة نبذة عنا، صفحة تسجيل الدخول) |
| `user-avatar-default.png` | الصورة الافتراضية للمستخدم قبل رفع صورته الشخصية |
| `factory-photo.jpg` | صورة المصنع في صفحة "نبذة عنا" |
| `products/slide-1.jpg` `slide-2.jpg` `slide-3.jpg` | صور شريط الهيرو المتحرك في الصفحة الرئيسية |
| `products/mattress-1.jpg` ... | صور منتجات المراتب (صفحة المنتجات) |
| `products/sofa-1.jpg` ... | صور منتجات الكنب (صفحة المنتجات) |
| `products/car-1.jpg` ... | صور منتجات السيارات (صفحة المنتجات) |
| `products/pack-1.jpg` ... | صور منتجات التغليف (صفحة المنتجات) |

ملاحظات:
- حتى تضيف صورك الحقيقية، ستظهر صور بديلة (Placeholder) تلقائيًا حتى لا تظهر الصفحة فارغة.
- يفضل أن تكون صور المنتجات بمقاس مربع أو أفقي (مثال: 600×450) وبحجم لا يتجاوز 300 كيلوبايت لكل صورة لسرعة تحميل أعلى.
- لإضافة أو تعديل منتج، افتح `js/script.js` وابحث عن `productCategories` وعدّل الاسم، المقاس، السعر، ومسار الصورة.
