# فيلورا للإسفنج والمراتب

نسخة محسّنة للمشروع الجامعي، تشمل واجهة الموقع، المنتجات، الطلب المخصص، السلة، الحسابات، التواصل ولوحة التحكم.

## أهم التعديلات
- شعار محلي جديد داخل `images/logo.png`.
- صور منتجات محلية جديدة داخل `images/products/`.
- 14 منتجًا موزعة على 4 فئات، ولكل منتج: الاسم، الوصف، الكثافة/النوع، المقاسات، والسعر الاسترشادي.
- الأسعار المعروضة هي **أسعار تجريبية للمشروع** ويمكن تعديلها من `js/script.js`.
- إصلاح إنشاء الحساب باستخدام JavaScript أصلي لا يعتمد على مكتبة خارجية.
- منع تكرار اسم المستخدم والبريد.
- تسجيل الدخول والطلبات والسلة والرسائل تعمل محليًا باستخدام `localStorage`.
- لوحة تحكم في `admin.html`.
- دعم البحث عن المنتجات وتفاصيل المنتج.

## التشغيل
1. فك ضغط الملف.
2. افتح المجلد `foam-site-V4`.
3. افتح `index.html` مباشرة، أو استخدم Live Server.
4. يفضل تشغيله من خلال Live Server أثناء التطوير.

## اختبار إنشاء الحساب
استخدم مثلًا:
- الاسم: Ahmed Ali
- اسم المستخدم: ahmed123
- البريد: ahmed123@gmail.com
- كلمة المرور: Ahmed12345
- تأكيد كلمة المرور: Ahmed12345
- ثم وافق على الشروط واضغط إنشاء الحساب.

## اختبار الطلب
المنتجات → تفاصيل/أضف إلى الطلب → أدخل المقاسات → أضف للسلة → إتمام الطلب → بيانات العميل → إرسال الطلب.

## لوحة التحكم
افتح `admin.html` لمشاهدة العملاء والطلبات والرسائل وتغيير حالة الطلب.

## ملاحظة مهمة
هذه نسخة Front-End محلية مناسبة للعرض والمشروع الجامعي. لا تستخدم `localStorage` لتخزين كلمات المرور في موقع تجاري حقيقي؛ عند تحويل الموقع إلى موقع فعلي يجب إضافة Backend وقاعدة بيانات ومصادقة آمنة وإرسال OTP حقيقي.
